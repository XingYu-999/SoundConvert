# V0.12.12 断链自动重连与默认开启设置

日期：2026-10-22。用户要求：软件与虚拟声卡意外断链后自动重连，设置中提供配置且默认打开。本轮修改客户端运行时与设置界面，固件通信协议保持现有接口；没有烧写实板或操作电脑网络配置。

## 修改前后

| 项目 | 修改前 | V0.12.12 |
| --- | --- | --- |
| 控制连接恢复入口 | 依赖正在监听及管理会话 | 成功连接后独立记录目标，空闲和停止播放也可恢复 |
| 重试上限 | 原音频恢复失败超过 5 次后停止 | 控制断链首次等待 1 秒，失败后等待 2、5、10 秒，后续持续按最长 10 秒等待 |
| 设置 | 只有后台启动时连接上次设备 | 新增独立的“与虚拟声卡意外断链后自动重连”，默认勾选，修改立即保存 |
| 首次连接失败 | 不属于已成功会话 | 继续保持失败终态，只有曾成功连接的当前目标才进入自动重连 |
| 目标校验 | 旧恢复逻辑直接尝试旧地址 | 原网卡、永久 ID 校验，旧地址失败后在原网卡通过 UDP 发现匹配目标 |
| 主动结束 | 手动停止与恢复逻辑耦合 | 显式断开、取消、关闭设置或退出均停止当前重连；首次失败不自动无限拨号 |

设置字段为 `AutoReconnectEnabled`，缺少该字段的旧 JSON 也默认 true，显式 false 会持久保存。不改变 `AutoConnectLastDevice` 的启动选项。主要代码为 `Runtime/BridgeRuntime.Reconnect.cs`、现有状态轮询及 `App/Views/SettingsPage.axaml`。

## 恢复行为

断链后释放旧控制、播放、麦克风和过期写入对象，在重试间隔内释放忙碌状态。每次重新握手和读取板卡实际状态；重新连接过程中可以用原有“取消连接”按钮停止。失败和等待原因显示在状态栏与设备连接卡片中。

原网卡无链路或无有效 IPv4 时等待它恢复；原网卡 IPv4 变化时，仅在该网卡能确定唯一可用地址时采用新源地址。不会改用其他已连接网卡。成功使用过的已知地址即使在电脑子网之外也可继续尝试；发现新地址时仍只接受同一永久 ID、原网卡上的可达子网候选。每次 TCP 握手再次核对永久 ID，旧 IP 上变成其他设备时拒绝读取后续配置。

恢复断链前的监听/麦克风请求，停止播放的状态不会被自动改成开始播放；USB STOPPED 保持停止，已有监听请求可保持等待 USB 启动。不重复发送一次性 HID、内部音量或配置事务写入。存在待处理网络配置事务时停止自动重连，保留显式查询/确认/回滚流程。关闭开关会取消活动重连；重新打开时可以恢复尚未被显式断开或取消的中断目标。

## 软件验证

最终检查结果与发布文件 SHA-256 见 `artifacts/acceptance/v0.12.12/summary.json`、`artifact-hashes.json`，截图位于相应检查目录。正式发布的 App/Runtime/Core DLL 与独立后台替身测试加载的 DLL 逐字节比较。

最终结果：自动重连专项 26 项、原取消专项 17 项、完整后台界面回归 744 项、原生界面回归 391 项全部通过。

专项使用生产运行时、真实命名管道和本机 TCP 板卡替身，覆盖：

- 新配置和缺字段旧配置默认开启，修改立即保存，启动自动连接关闭时仍能断链恢复。
- 空闲及停止播放后的重连，USB 停止时保留监听请求且不隐式启动 USB。
- 关闭设置不重连，重连 HELLO 等待中关闭开关可取消；显式断开及取消后不继续拨号。
- 原 IP 设备身份变化时拒绝后续配置，恢复原身份后可重试成功。
- 原网卡断开后等待恢复、不转移网卡；通过注入发现结果找到同身份的新地址/端口。
- 连续第 6 次失败后仍处于重连等待，间隔上限为 10 秒。
- 待处理配置事务不重放；已知子网外目标的恢复；重连等待期间退出会结束后台。
- 原取消连接专项和完整后台界面回归，另完成原生界面回归 391 项。

注入发现结果只是校验恢复流程，不等同于实际 DHCP 改址或跨路由网络测量。音频请求状态的恢复不代表真实 WASAPI 播放、麦克风传输或 USB Host 听感已经实测。

## 发布与实际验收

Windows 自包含目录：`SoundConvertClient/artifacts/publish/v0.12.12-win-x64/`。前台及后台版本为 0.12.12.0，使用完整目录并保留 Engine 子目录。固件同步构建用于版本一致性；本功能复用既有 TCP/UDP 接口。

实板尚待验证：有声/空闲/停止播放分别拔插网线，设备重启、DHCP 地址变化、原网卡地址变化、长时间离线后恢复，以及等待中关闭开关/取消/退出。核对仅重连原设备、不恢复主动停止的播放、不重放配置或按键，并单独测量实际音频恢复中断。若相同条件下实际更差，回退完整 V0.12.11 程序目录，保留设置、日志及失败窗口。

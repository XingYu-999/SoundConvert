# V0.9.1 网络名称与接收地址显示

日期：2026-10-21。本批由根目录 `VERSION` 的 0.9.0 递增一次至 0.9.1。

同一工作区随后由其他聊天推进至 V0.9.2、V0.9.3；本批保留其修改，没有再次递增或回退版本。最终客户端按 V0.9.3 源码快照构建，独立目录为 `artifacts/releases/V0.9.3-network-name`，避免与其他聊天的发布输出互相覆盖。

## 变更

- 网络主机名固定为 `W5500-EVB-Pico2`，与应用内发现的型号共用常量。DHCP Discover、Request、T1 续租及 T2 重绑定均携带 Option 12 主机名；不修改已保存的 USB 产品名、播放名、IP 或 MAC。
- W5500 空闲 Socket 7 提供 UDP 137 的 NetBIOS 节点状态查询及本机工作站名称查询，应答名称为 `W5500-EVB-Pico2`。不提供文件共享。每 100 ms 最多处理一个报文，仅回应同子网有效单播来源；在播放及采集服务之间轮询，应答沿用非阻塞 SENDOK 管理。链路断开或改址时关闭套接字并重新初始化。
- 虚拟声卡页移除“本地接收 IPv4（由所选网卡确定）”标签和只读输入框，设备 IPv4 输入框使用完整宽度。保留网卡下拉框及网卡详情中的 IPv4；TCP、播放接收、麦克风发送仍由所选网卡确定本地地址。

协议依据：[RFC 2132，Host Name Option](https://www.rfc-editor.org/rfc/rfc2132.html)、[RFC 1002，Node Status Response](https://www.rfc-editor.org/rfc/rfc1002.html)。这里实现无 scope 的查询应答子集，不宣称完整 NetBIOS 注册、WINS 或 SMB 支持。

## 实板与生效边界

本批未烧写开发板、未访问 COM8，未进行实际 NetBIOS 扫描、DHCP 租约更新或真实 USB 音频验收。截图中的固件 V0.8.0 和旧名称不能视为已被本批修改替换。

局域网名称需更新固件后重新扫描；DHCP 主机名需在新租约请求或续租时发送，路由器是否更新 DNS/PTR 取决于其配置。扫描工具可能优先使用已有 DNS/PTR 或本身的旧结果缓存，无法由开发板强制覆盖。当前环境对 `192.168.8.73` 的只读 PTR 查询返回名称不存在，未确认截图中 `iDRAC-87L3Z03` 的来源。

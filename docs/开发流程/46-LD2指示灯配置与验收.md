# LD2 指示灯配置与验收

本批版本 **V0.12.2**，日期 2026-10-22。面向 W5500-EVB-Pico2 V1.0 的 GPIO25／LD2，不改变电源灯或网口指示灯。

## 使用

“虚拟声卡”页的“声卡配置与模拟”卡片最底部增加“LD2 指示灯配置”。选择模式仅修改草稿；点击卡片上方“保存声卡配置”才提交，重启后保留。“放弃修改”恢复已保存模式，刷新状态／配置保留未保存草稿。保存沿用现有声卡配置流程：如正在模拟，会停止双向音频和 USB 模拟，完成事务后恢复原模拟与音频意图，Host 会重新枚举。

| 模式 | 行为 |
| --- | --- |
| 自动（默认／推荐） | USB 声卡成功枚举、RUNNING 且未挂起时，空闲以 2.4 秒周期呼吸；播放 OUT 或麦克风 IN 有实际音频传输时，约每秒闪烁 3.1 次；无连接、停止模拟或挂起时熄灭。 |
| 常灭 | LD2 关闭。 |
| 常亮 | 固件运行时持续点亮。 |
| 持续呼吸 | 固件运行时以 2.4 秒周期持续呼吸。 |
| 持续闪烁 | 固件运行时每秒闪烁一次。 |

“闪灯识别（5 秒）”临时以 5 Hz 覆盖所选模式，包括常灭，结束后恢复最新已提交模式，不写 Flash。协议仍允许 1–30 秒。指示灯配置使用防滚轮误切换的下拉框；关闭时滚轮仍用于页面滚动。

连接指 USB 声卡的 Host 枚举状态，与管理软件是否打开、TCP 是否连接无关。有数据流指音频传输，静音或全零 PCM 仍算数据；控制包、仅有历史累计计数或选择了 alt 都不会持续触发音频灯态。约 200 ms 没有新音频传输后返回呼吸，不跟随每个 USB 包翻转灯光。

旧固件不声明配置能力时，下拉框禁用并提示更新配套固件；保存其他参数不发送新字段。未知已保存模式保留原值，保存前要求明确选择已支持模式。

## 实现与兼容

- `uab_indicator.c` 在 Core 0 独占 GPIO25 硬件 PWM，无 PWM 中断；主循环每 10 ms 采样一次已有 USB／麦克风状态快照并有界更新占空比，不等待、不扫描 PCM、不在灯效路径写 Flash。Core 1 通过原子请求设置模式或临时识别。
- 默认约 1 kHz PWM 载波，呼吸曲线采用平方亮度渐变。实际闪烁／亮度效果尚须实板观察。
- `GET_CAPABILITIES` 增加 `indicator_configuration_supported`／`indicator_modes`；`GET_CONFIG.usb.indicator_mode` 读回已提交模式；模式随原配置事务在成功确认后生效，失败／回滚保持原设置。
- Flash 记录升级为 v8／796 字节，在 v7 尾部追加一字节模式。兼容读取 v1–v7，旧记录默认自动，保留其他配置。保留原双槽 CRC／独立提交页／写前停止模拟／断电回退校验。
- 前台通过 `IBridgeView`、MainViewModel 代理和 Engine 快照序列化传递选项、草稿、能力与识别命令，音频与板卡连接仍由独立后台管理。

## 实板验收边界

本批未烧写、未复位开发板、未操作 COM8，未将编译、替身或截图结果当作实板验收。待使用本版固件验证：

1. USB Host 未连接／连接空闲／播放／停止或暂停／挂起及恢复的灯态；Host 暂停后若仍传输静音 PCM，应继续按有流显示。
2. 麦克风单向、播放单向及双向传输；200 ms 无新数据后的回退。
3. 五种模式保存、断电重启保留；常灭下主动识别后自动恢复常灭。
4. 呼吸亮度、实际闪烁节奏和真实鼠标滚轮行为；音频连续性和更新前后同条件计数比较。

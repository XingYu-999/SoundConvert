# V0.11.10 启动控制台闪窗修复

前台项目从 `Exe` 改为 `WinExe`，由 Windows 直接按图形程序启动。正常打开、登录启动使用的 `--tray` 路径均不会申请控制台；删除 Avalonia 初始化中的 `FreeConsole()`，消除“先创建黑窗口，再关闭黑窗口”的启动过程。

命令行分支在运行诊断命令前调用 `AttachConsole(ATTACH_PARENT_PROCESS)`，复用启动它的现有终端；没有父控制台时也不创建新控制台。保留父进程提供的标准输出／错误重定向、JSON 结果和退出码。依据见 Microsoft 的 [AttachConsole](https://learn.microsoft.com/en-us/windows/console/attachconsole) 和 [GetStdHandle](https://learn.microsoft.com/en-us/windows/console/getstdhandle) 文档。

此次修复批次递增为 V0.11.10，固件通过根目录 VERSION 同步版本，未修改固件业务逻辑。用户配置目录和已有设置保持原有读写方式。并行的通信端口／枚举模式界面批次随后将共享工作区推进至 V0.11.11，保留本次启动修复；最终使用该合并版本，不回退根目录 VERSION。

本轮未执行固件烧写、COM8 联调、真实 USB Host 或实板录放验收；构建与软件检查不能代替这些结果。

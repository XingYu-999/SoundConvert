# V0.11.5 播放页稳定性与诊断布局验收

日期：2026-10-22。本批次从 V0.11.4 递增一次补丁版本至 V0.11.5，重试和验证不再递增。

## 布局调整

- “应用并重新开始输出”移到缓冲上限数值输入框右侧，两者作为一个水平组合，换行时也保持相邻。
- 稳定性设置使用整行宽度；其下新增“诊断”分区。
- “诊断”标题下先显示有效音频包数，再并排显示缓冲水位和时钟漂移两张趋势图。
- 应用命令、缓冲值绑定、图表采样／断点／清空逻辑保持原有实现；输入框继续禁用上下按钮及滚轮调整。

## 验证

- 固件与客户端／Engine 统一构建发布通过，客户端 0 警告／0 错误；1229 项现有协议／音频离线检查通过。日志：`artifacts/diagnostics-layout-build.log`。
- 319 项原生 Avalonia 界面检查通过，结果：`artifacts/acceptance/v0.11.5/ui/result.json`。
- 已查看 1400×940 和 1050×680 截图：按钮与输入框相邻，诊断区在稳定性设置下方，两张趋势图并排，窗口较小时按页面正常滚动查看。截图：`trends-controlled.png`、`trends-controlled-small.png`，曲线为受控测试数据。
- 本批仅调整布局，未新增测试用例，复用既有回归及截图核对；未重复执行未受影响的原生菜单和生命周期矩阵。

固件仅同步版本，未刷写、未执行 COM8 联调或真实音频录放。本批结果不能替代实板音频验收；前批未测范围继续按文档36及对应历史记录理解。

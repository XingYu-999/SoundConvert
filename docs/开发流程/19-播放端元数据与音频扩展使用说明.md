# UAC1音频与媒体按键使用说明

当前 V0.9.4。文件沿用旧名以保留历史链接；歌曲信息功能已删除。

1. 将开发板USB接到Windows／Android音源主机，以太网接到电脑所在网络。
2. 电脑选择实际网卡、连接开发板；输出选择“耳机 (Realtek(R) Audio)”。USB Host选择开发板播放端点。
3. 音量＋／音量−／静音／播放暂停／上一曲／下一曲由USB HID Consumer Control发送。它们不读取播放器信息；“已接受”仅表示板卡接受请求，须在Host确认实际响应。结果未知时不自动重放切换键。
4. “声卡内部音量”影响板端USB OUT到网络PCM的增益，范围0–100%，上电默认80%。80%表示线性幅值0.8（约−1.94dB），不是Host系统百分比，也不是电脑耳机端点音量。内部静音在渐变结束后输出全零PCM。配置不写Flash；USB软停止／启动保留，板卡重启恢复80%及非静音。
5. Host标准UAC1 Feature Unit音量／静音仍由Host控制；最终播放幅值为Host FU增益×板内百分比。Host写入不会改写内部百分比。电脑输出端点音量、本地监听增益独立保留。
6. 麦克风传输在“输入”页显式选择并启动，默认不采集。录音方向FU7与播放FU2及内部播放增益独立。

不再需要配套媒体APK、通知访问、歌曲来源选择、会话绑定、TLS邀请或封面缓存服务。旧电脑程序必须退出前台及Engine后，完整换用新目录，IPC3不兼容旧前后台混用。旧固件未声明internal_volume_control_supported时内部音量控件禁用，不退回Host设置接口。

配置预设、格式和网络仍通过验证／准备／应用／确认事务保存。更改内部运行音量不使用配置事务，不保存Host或播放器状态。

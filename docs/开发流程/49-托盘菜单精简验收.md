# 托盘菜单精简验收

版本 **V0.12.5**，日期 2026-10-22。

根据用户截图，托盘菜单的设备名称移到最上方，继续读取真实连接名称，不硬编码或修改设备名称。删除“Host 播放器与音量键”、按键反馈、HID 就绪说明、“电脑输出音量”标题，以及托盘的开始／停止输出按钮。六个 Host 按键、电脑音量滑块、静音和菜单导航保留，音量百分比与滑块同排显示。按钮悬停提示及无障碍名称继续保留。

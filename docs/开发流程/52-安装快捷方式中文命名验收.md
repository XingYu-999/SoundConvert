# 安装快捷方式中文命名验收

日期：2026-10-22。最终交付版本：**V0.12.10**，统一读取根目录 VERSION。

根据用户安装截图，将桌面快捷方式、开始菜单文件夹和菜单中的启动项统一命名为“USB 音频桥接工具”，与现有窗口标题及关于页名称一致；卸载项命名为“卸载USB 音频桥接工具”。程序 EXE 文件名、AppId 及安装目录保持原有规则。

`UsePreviousGroup=no` 确保已有英文安装升级后使用中文菜单文件夹。安装成功后检查已知旧桌面／菜单 `.lnk` 的完整 TargetPath，仅删除指向本安装 EXE 或卸载器的旧英文快捷方式。旧菜单文件夹为空时才移除；保留同名但指向其他程序的快捷方式、无法读取的快捷方式以及其他文件。当前用户与所有用户模式均使用安装范围对应的 shell 目录。

在隔离 AppId、测试载荷和项目内桌面／开始菜单目录中执行真实 Inno 安装升级流程，**9 项检查通过**：

1. 旧版安装生成英文桌面及菜单条目。
2. 升级生成中文桌面、菜单文件夹、启动及卸载条目。
3. 安装记录中的英文 Icon Group 更新为中文。
4. 中文快捷方式仍指向正确的 EXE 和卸载器。
5. 本安装所属的旧英文快捷方式被移除。
6. 同名但指向其他程序的快捷方式及无关文件被保留。
7. 修改安装取消桌面图标时仅移除中文桌面快捷方式，菜单条目保留。
8. 旧英文菜单文件夹为空时被移除。
9. 卸载清理本次生成的中文菜单条目。

原始脚本为 `artifacts/Test-ChineseInstallerShortcuts.ps1`，结果及安装日志位于 `artifacts/acceptance/v0.12.10/chinese-shortcuts/`。这些检查使用 Windows 实际 `.lnk` 文件及 Inno 安装日志，未改动用户真实桌面、开始菜单或现有应用安装。

前台及 Engine 已发布至 `SoundConvertClient/artifacts/publish/win-x64`，四个 EXE／DLL 文件版本核对为 `0.12.10.0`。安装包在父目录 `SoundConvertClient/artifacts/publish/SoundConvertClient-Setup-V0.12.10-x64.exe`，同目录提供 SHA256。

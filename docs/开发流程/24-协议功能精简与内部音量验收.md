# 协议功能精简与内部音量验收

2026-10-21，本批变更版本V0.9.3。工作区另有前后台生命周期、网络名称及系统默认音频设备批次，根VERSION随后到V0.9.4；保留其代码并统一构建V0.9.4，不再次递增。独立交付目录`artifacts/releases/V0.9.4-uac-cleanup`，避免覆盖其他聊天产物。

## 最终行为

- 删除歌曲标题、歌手、封面、时长与进度；删除Windows／Android媒体适配和发送应用、来源会话绑定、配对／TLS/WSS服务、缓存处理、IPC歌曲字段、界面入口及相关依赖。手机上的旧配套／测试应用已在此前清理步骤卸载；本批不安装或启动手机采集。
- 删除Windows Host绝对音量滑块／静音设置、Host端点写入API、USB_SET_VOLUME及播放FU网络写入邮箱。工具不再直接写Host端点音量；保留USB序列号身份匹配，防止把开发板自身选为电脑输出。
- 保留UAC1音频及标准类请求、六个USB HID Consumer Control键、录音方向FU7、DSP／电平和电脑实际输出端点音量。按键接受／传输完成不代表播放器状态；不再读取歌曲验证按键。
- 新增独立SET_INTERNAL_VOLUME：整数0–100%与内部静音，上电默认80%及非静音；Core1邮箱交给Core0，状态通过internal_volume报告。运行期有效、不写Flash，USB软停止／启动保留，板卡重启恢复默认。旧固件未声明新能力时控件禁用，不回退到已删除的Host设置。
- 80%=0.8线性幅值，约−1.94dB。与Host FU增益相乘后一次处理PCM，保留1ms渐变；Host音量写入不改变内部百分比，任一路静音最终全零。录音方向独立。

## 实板边界

本批没有暂停／烧写／复位开发板，没有COM8启动验收，没有手机按键、真实音量幅值、USB软断连或断电默认值实测。本批未修改实际用户设置和耳机音量；真实发布检查只在隔离数据目录选择耳机，不创建音频流。固件离线、替身和发布启动不能代替实板结果。

将来更新实体板后需按[剩余工作内容](../剩余工作内容.md)逐项完成，并使用COM8/115200/8N1和指定Realtek耳机。前台与Engine需同时退出并完整升级，IPC3拒绝旧命令，旧固件内部音量禁用。

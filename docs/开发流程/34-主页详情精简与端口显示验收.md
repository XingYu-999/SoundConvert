# V0.11.2 主页详情精简与端口显示验收

日期：2026-10-22。本批次仅递增一次补丁版本，由 V0.11.1 到 V0.11.2。

## 修改

- 删除主页 Host 快捷控制中的“控制与音量详情”折叠区及其内容。
- 删除主页“设备身份与端口”折叠区及其内容。
- 在“开发板与 UAC”卡片直接显示通信端口：控制 TCP、设备发现 UDP、声音输出 UDP、声音输入 UDP。
- 控制端口读取 `ControlPortLabel`；声音输出读取 `PlaybackPorts`（开发板 → 软件），声音输入读取 `CapturePorts`（软件 → 开发板）。活动流读取协商后的真实端口，无活动流时使用既有默认端口；设备发现固定 UDP 49160。
- 前台、独立 Engine 和固件统一使用根目录 VERSION。没有修改音频与固件运行逻辑。

## 验证

统一 Release 构建／发布及现有离线检查记录：`artifacts/home-ports-build.log`。原生界面回归与截图：`artifacts/acceptance/v0.11.2/ui`。实际结果：固件编译和 Windows 自包含前台／Engine 发布通过，客户端 0 警告／0 错误；1229 项现有离线检查、311 项原生界面检查通过。已查看主页截图，确认两处折叠区移除、通信端口及方向常显，原有输出和输入选择器在标准窗口首屏可见。前台与 Engine 文件版本均为 0.11.2.0，实际程序 --version 返回 V0.11.2。

未刷写固件，未执行 COM8 联调或真实音频测试。V0.11.1 HID 上下曲真实 Host 复验仍未完成，不因本批界面修改而记为通过。

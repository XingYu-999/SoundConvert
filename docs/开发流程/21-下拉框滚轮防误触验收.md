# V0.8.1 下拉框滚轮防误触

日期：2026-10-21。基线版本 V0.8.0，本批次仅递增一次补丁版本至 V0.8.1。

## 修改范围

统一替换桌面上位机的 8 处下拉框：电脑监听输出、输入源、搜索网卡、USB 设备类型、设备网络地址模式、传输压缩、重采样质量、元数据配对来源。

`SoundConvertClient/App/Controls/NoWheelComboBox.cs` 继承标准 ComboBox，保留原有主题、模板与数据绑定。下拉框收起时不调用原有滚轮切换处理，也不吞掉事件，父级页面继续滚动；展开时保留原有弹出列表滚动，点击及键盘选择保持可用。6 个包含下拉框的视图统一使用此控件。

固件读取根目录 VERSION 同步为 V0.8.1。与 V0.8.0 发布源码清单比对，固件 C/H 源码没有变化；未修改协议或音频处理。

首次全量构建在固件编译成功后，因沙箱无法访问本机 Windows SDK 目录而中止；随后获准在沙箱外执行相同 .NET 还原与构建并通过。界面检查工具自身有既存 `Bitmap.Save` 废弃 API 警告，不影响本次检查结果。

此次滚轮行为依据控件实现和调用路径检查；现有界面套件不模拟物理鼠标滚轮，未将其记为人工鼠标操作验收。界面套件使用 TCP 设备替身、注入输出及隔离配置，不连接实板或写入真实音频端点。

## 交付与边界

运行 `artifacts/releases/V0.8.1/client-win-x64/SoundConvertClient.exe`，保留同目录依赖及 Engine、Media.Windows 子目录。升级时通过旧程序的退出功能结束旧前台与后台，再启动新版本。

固件产物位于 `artifacts/releases/V0.8.1/firmware`，本次仅同步构建。未烧写开发板，未进行 COM8 联调、USB 枚举或实板音频验收；V0.8.0 的实板记录仍归属于原版本。本次交付包含桌面客户端和正式固件，不重新打包 Android 或独立播放端配套组件。

## 分层验证结果

最终机器可读结果、计数、窗口及限制以证据目录 `results.json` 为准。

1. 最终 Core 离线 **897 项通过**，含 Span 编码字节一致、发送工作线程稳态分配 delta=0、积压时间线与 SRC/乱序/FEC/格式边界。这个“零分配”仅适用于被测发送稳态，真实采集 callback 单独计数，不能扩大到 NAudio 全链路。
2. 板端宿主 C 检查通过；USB IN 麦克风 **2166 项**，覆盖 2ms 平滑、16/24-bit、partial write、停止/重启；另含 HID、配置断电/回滚、USB 所有权、发送完成和期限。完整日志为 `offline-firmware-final.log`。
3. 设置迁移 **10 项**、系统默认音频端点 **29 项**通过。新旧 schema、false 保留、备份、损坏设置无任意目标、默认端点切换/排除板自身与失败回退分别检查。
4. 最终原生 UI **252 项**通过；较早完整 IPC/交互 **627 项**通过。最新 `engine-ui-delivery` 执行到622项时因滑块单帧最大471.59ms超过150ms门槛失败（p95=15.90ms）；同次200个输出pending首帧p99=3.28ms。失败保留，不以旧通过覆盖。范围为原生渲染与STOPPED USB替身，没有冒充实际WASAPI启停或Host响应。
5. 生命周期包含真实 UI 退出、10 次仅结束 UI PID、同后台重接、单实例、版本/身份拒绝、卡住 IPC 停止失败、过期操作 Unknown 及 8 个不读响应客户端压力。最终数量见 `lifecycle-final/result.json`。
6. 实板双向、500 次控制和声音连续窗口结果在本节后续表格与 `results.json` 单独列出，不以以上替身通过代替。

## 验收边界与回滚

验证指南的全矩阵仍按原门槛保留：20/40/80ms 各 10min×3、高格式每组合 10min、30min 综合压力、2h 候选/8h 发布长稳、1/6s 断网和完整故障注入、所有 DPI/读屏、四模式实枚举及主观耳机听音，不能由一次短窗或截图推定通过。实际完成的子集和未测项在最终结果中逐项标记；本批完成实现与注明范围的自测，不将未执行的长稳写成正式发布验收。

数字 loopback 录音只能证明 Windows 混音路径；Host USB IN 录音证明回传数字路径，不能单独证明耳机模拟输出没有 click/pop。没有人工盲听记录时不声称“无明显爆音”主观通过。其他 Host（Android/NS2）、其他网卡/端点与驱动不由当前 Windows 结果覆盖。

回滚使用整套匹配的 App/Runtime/Engine；先显式停止后台。设置迁移保存 `settings.schema1.bak` 和原子替换备份；Flash 配置记录格式未改。常规 SWD 更新保留配置区，不使用整片擦除。测试结束恢复所改的端点音量/静音；用户原始设置保持在正常数据目录。

# V0.11.11 通信端口迁移与枚举模式中文化验收

日期：2026-10-22。本批次仅递增一次补丁版本，由 V0.11.10 到 V0.11.11。

主页“开发板与 UAC”卡片删除通信端口区块及分隔线。原有内容移入“虚拟声卡 → 设备连接 → 详细信息”，默认收起；保留控制 TCP、设备发现 UDP、声音输出及声音输入 UDP 端口和方向。继续绑定 ControlPortLabel、PlaybackPorts、CapturePorts，活动流使用既有协商端口，无活动流时使用既有默认值。

主页“当前枚举模式”在显示层转换为中文：desktop_speaker → 音箱、speaker → 通用音箱、headphones → 耳机、headset → 耳麦，unknown、空值或未知扩展值 → 未知。后台协议值、USB 类型配置与保存流程保持原样，断开后仍按当前设备未知状态显示。

前台、独立 Engine 与固件统一读取根目录 VERSION；更新日志与说明同步维护。

## 验证

固件及上位机 Release 编译通过，上位机 0 警告／0 错误，现有 1253 项离线检查、345 项原生界面检查通过。已查看主页及虚拟声卡截图：主页端口区块移除、未连接的枚举模式显示“未知”，虚拟声卡设备连接卡片显示默认收起的“详细信息”入口。四种已知模式的中文名称由主页显示转换器映射，协议标识保持原值。

构建日志：`artifacts/home-details-build-full.log`；发布日志：`artifacts/home-details-publish.log`。原生界面回归与截图：`artifacts/acceptance/v0.11.11/ui`。最终软件交付结果：`artifacts/acceptance/v0.11.11/software-delivery.json`。前台与 Engine 文件版本均为 0.11.11.0，实际发布前台 `--version` 返回 V0.11.11。

首次受限环境中的 SDK 还原失败，随后在常规 Windows 环境构建成功。默认发布目录被正在运行的旧前台占用；保留原运行进程，改在独立 V0.11.11 目录发布成功。失败与重试日志分别保留，不重复递增版本。

本轮未执行固件烧写、COM8 串口联调、真实 USB Host 或实板音频验收。固件仅同步版本，编译、协议替身和原生界面检查均不代替实板结果。

## 使用

退出旧版后运行 `artifacts/releases/V0.11.11/client-win-x64/SoundConvertClient.exe`，完整保留 Engine 子目录。

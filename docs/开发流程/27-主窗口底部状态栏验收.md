# V0.9.5 主窗口底部状态栏

日期：2026-10-21。本批次从 V0.9.4 递增一次补丁版本至 V0.9.5。

## 行为与范围

- 主窗口底部新增 28 DIP 高、橙色背景、白色文字的状态栏，横跨导航栏及工作区，右侧显示根目录 `VERSION` 对应的 `V0.9.5`。
- 原顶部黄色全局提示移入状态栏，继续绑定现有 `GlobalError` / `HasGlobalError`，包含前台本地错误及后台快照错误。没有全局错误时显示现有 `Status`。
- 消息单行显示，过长时省略，工具提示保留完整原文。状态栏位于滚动区域外，页面滚动、切页及导航展开／收起时保持固定位置。
- 原操作进度浮层保留在工作区底部、状态栏上方，继续显示操作过程并在结束时隐藏。
- 生产实现仅调整 `MainWindow.axaml` 布局及绑定；已有浮层布局回归改为相对工作区底边核对间距。未新增状态来源、IPC 字段或固件功能，固件仅随根目录版本同步构建。

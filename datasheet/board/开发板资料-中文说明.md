## 固件需要保留的板内引脚

以下对应关系以原理图为依据，方向以 RP2350 为参照。

| GPIO | 信号 | 说明 |
| --- | --- | --- |
| 16 | SPI0 RX / W5500 MISO | 输入 |
| 17 | SPI0 CSn / W5500 SCSn | 片选，低有效 |
| 18 | SPI0 SCK | 时钟 |
| 19 | SPI0 TX / W5500 MOSI | 输出 |
| 20 | W5500 RSTn | 复位，低有效 |
| 21 | W5500 INTn | 中断输入，低有效 |
| 23 | SGM62112 MD/SYNC | 电源工作模式控制 |
| 24 | 电源分压观测，官网称 VBUS 检测 | V1.0 图中 R2/R4 上端在 D2 后、与 VSYS 同节点；独立供电时不能据此证明 USB 已拔线 |
| 25 | LD2 | 用户 LED |
| 29 / ADC3 | VSYS 检测 | 分压后经 Q1 接入 |

外接接口还应参考原理图上的 J1/J2 物理针脚号，GPIO 编号不能直接当排针序号。SW1 接 Flash 片选相关启动电路，SW2 接 RUN 复位；J3 为 SWD。

## 原始资料中的不一致

这些说明只用于避免误读，没有改动官方原件。

1. 官网写有“集成 16 Mbit Flash”；原理图和 BOM 明确存在独立 U2，RP2350A 手册也列为无内置 Flash。本板存储容量来自外置芯片。
2. 官网部分引脚说明仍写 Micro-USB、LDO；V1.0 原理图显示 J6 为 USB-C，U1 为 SGM62112-3.3 开关式升降压芯片。
3. BOM 的 U4 描述写有 Cortex-M3+ / 133 MHz，与 RP2350 手册不符；以具体型号和主控手册为准。
4. BOM 的 Flash 描述含 QPI/DTR 字样，不能代替完整料号对应的指令规格。
5. BOM 将 L2、L3 放在同一条 2.2 µH 记录中且数量列为 1；原理图显示 L2 为 2.2 µH、L3 为 3.3 µH。若用于复刻采购，须先向板厂核实。
6. 官网板卡电源范围表列 VSYS 为 4.3–5.5 V。即使电源芯片本身支持更宽输入，也不据此扩大整板供电范围。
7. 官网将 GPIO24 称为 VBUS sense；本地归档原理图 PNG 的 R2/R4 取样点却在 D2 后，与 VSYS 同节点。这是依据图纸的判断，需按实物版本测量复核；不能直接用此脚区分独立供电下的 USB 拔线与 Host 挂起。声卡配置改为以应用主动“停止模拟”完成为前提，见 [USB 开发指南](../../docs/08-USB声卡开发指南.md)。

本次只完成文件归档与资料核对，没有测量实物供电、USB 兼容性、以太网吞吐量，也未在 Altium 中完成工程重编译或生产检查。
